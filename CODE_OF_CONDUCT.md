# Code of Conduct

This project follows the
[Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful, assume good faith, keep feedback about the work, and
accept that the maintainer makes the final call on scope.

Unacceptable behaviour (harassment, personal attacks, publishing others'
private information) can be reported privately to the maintainer through
GitHub, for example via a
[security advisory](https://github.com/roman-romanov-o/sich/security/advisories/new),
which is private to the maintainer. Reports are handled confidentially and may
lead to a warning, a temporary ban, or a permanent ban from the project
spaces, at the maintainer's discretion.
