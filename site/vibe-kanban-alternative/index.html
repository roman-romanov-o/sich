Pick Sich if

You run many agents at once

The board shows who is working, who is waiting on you and who is done. ⌃Tab jumps to the next one waiting.

You watch your limits

Live gauges for Claude subscription, API credit and Codex, with reset times.

You never want a surprise API bill

Sich only runs interactive sessions and refuses to spawn headless claude -p.

You want a native Mac app

Swift and AppKit, no Electron, no account, signed and notarized.

FAQ

Is Vibe Kanban shut down?

Its team announced the sunset on 2026-04-10 and turned off the cloud services about 30 days later. The open source local app is still on GitHub and is community maintained.

What is the best Vibe Kanban alternative on macOS?

It depends on what you used it for. For a native Mac kanban where each card is a live Claude Code or Codex terminal with quota gauges, try Sich. For cross-platform and built-in PR review, the community Vibe Kanban or Kanban Code fit better.

Can I move my Vibe Kanban tasks to Sich?

There is no importer. Recreate open tasks in the Sich BACKLOG; each one starts its agent in the project folder you pick.
