What it does

Starting five agents is easy. Keeping your head while five agents interrupt you is not.

Cards move by themselves

BACKLOG, QUEUE, WORKING, NEEDS YOU, DONE. Driven by the agents' own lifecycle hooks, no screen scraping.

The card is the terminal

Real sessions rendered in-process with libghostty. No second terminal app, no window juggling.

Quota gauges

Claude subscription, API credit and Codex limits with reset times, live on the board.

No surprise API bills

Sich only runs interactive sessions. It never spawns headless claude -p.

Focus blocks

A pomodoro holds agent questions until your break, then hands them back as one list.

Remote cards

Attach a tmux session on any SSH host. Its hooks are relayed back, so it moves like a local card.

⌃Tab to whoever needs you

Hold ⌃, tap Tab. NEEDS YOU comes first. Release and you are in that agent's terminal with its question on screen.

Nobody waiting? Take the next task

When NEEDS YOU is empty the board points at the BACKLOG. Click a task and its agent starts in that project.

Click a card, you are in the session

Box drawing edge to edge, smooth scrollback, paste, themes, ⌘↑ / ⌘↓ between your own prompts.

FAQ

How do I track multiple Claude Code sessions at once?

Run each session as a card in Sich. Claude Code hooks move the card to NEEDS YOU when it stops to ask something, and ⌃Tab jumps straight to it.

Is there a kanban board for Claude Code and Codex on macOS?

Yes. Sich is a native macOS app (Swift, AppKit) with a kanban board where each card is a live Claude Code, Codex, Cursor, Antigravity or Gemini CLI terminal.

How can I see my Claude subscription quota and API usage?

Sich shows live gauges for your Claude subscription, API credit and Codex limits, each with its reset time.

Can it spend my Anthropic API credits?

No. It only runs interactive sessions under your own login and refuses to spawn headless claude -p.

Does it work with remote machines?

Yes. Attach a tmux session on any SSH host as a card. Windows hosts work through psmux. Nothing is installed on the remote host.

What does it cost? Does it send my data anywhere?

Free and MIT licensed, no account. The only network calls are your own usage queries to the providers.
